# 手动验收清单

以下是待逐项记录的操作，不是已通过的结果。自动化localhost协议测试不替代本机双窗口与两设备LAN。

## 单窗口

- 本地黑白轮流，点击越界与占用，非法操作不换人。
- 四方向胜线、长连、终局停止与一次比分；新局保留累计比分。
- 保存、退出、继续；加载一份损坏的复制存档应保留当前局。
- 复盘首/前/后/末、自动播放到末尾暂停，复盘期间不能落子，退出后继续。
- 各AI等级；思考中切模式、改等级、重开或复盘，旧结果不得污染当前局。
- AI完成后立即保存，继续应含该手及可能的终局比分。
- 中文、按钮文字、logo、帮助弹窗与Retina坐标，检查遮挡、缺字和溢出。
- IP与端口编辑；带点端口、0、65536应拒绝。

## 两个本机实例

1. 启动两个应用实例，主机建房，客方用127.0.0.1及相同端口加入。
2. 交替落子，比较棋盘、回合、最后一手、胜负和比分。
3. 双方各提议一次重开，只有对方接受才清盘，比分保留。
4. 客方断开后同实例重连，恢复主机快照；新实例不得接管已提交身份。
5. 未完成首次握手时中断，再以新客户端尝试加入空房。
6. 保存退出后，主机“续盘建房”，客方“加入新房”，继续未完成局与终局重开。

## 两设备

接入可互通LAN，使用主机真实IPv4与相同端口。记录macOS网络权限、路由/AP隔离、断网约10秒检测、恢复后同实例重连。不要将127.0.0.1用于另一台设备，不要为了测试静默修改防火墙。

每条记录实际环境、步骤、预期、观察和结果；缺少设备时保留待验收状态。Intel、更旧macOS和Windows不在当前已验证平台内。
